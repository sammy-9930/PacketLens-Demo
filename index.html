      Run locally

      Play the bundled demo

      Press Play above. The bundled trace runs offline in a browser on Linux, Windows, or macOS.

      Build the sniffer and replay a capture

      From the repository root on Linux, use GNU Make, a C++14 compiler, and Python 3.

      cd projects/packet-sniffer
make
python3 benchmarks/replay.py --write-pcap sample.pcap
./cpp-sniffer --threaded --metrics-only --pcap sample.pcap > capture.jsonl

      Choose Open metrics file above and select capture.jsonl. A fast offline replay may produce just one interval.

      What capture threads mean

      The count includes one reader plus any decode workers. With cpus = 1, the reader also decodes. With cpus = 4, one thread reads and three workers decode. The --threaded command above uses one reader and one worker. Metrics-only mode adds a reporting thread. Threaded packet-line output adds a writer thread. Both are outside this count.

      Record live loopback traffic on Linux

      Run sudo ./cpp-sniffer lo to see throughput, packet totals, and protocol counts in the terminal about once per second. Use the command below to save dashboard metrics.

      Run this command from the packet-sniffer directory. Generate traffic with ping -c 5 127.0.0.1 in another terminal, then press Ctrl+C to finish the recording.

      sudo ./cpp-sniffer --threaded --metrics-only lo > loopback.jsonl

      Open loopback.jsonl in the dashboard to replay the recording.
